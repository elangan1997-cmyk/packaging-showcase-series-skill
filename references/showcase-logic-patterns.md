# 包装案例展示逻辑库

本文件总结优秀包装设计师与工作室公开案例中反复出现的展示方法。学习的是信息架构、镜头节奏和证明方式，不复制具体作品、构图、道具或签名风格，也不在图像提示词中写“某某风格”。

## 选择方法

先回答：这个项目最值得被证明的是什么？

| 核心价值 | 主叙事原型 |
|---|---|
| 文化符号、造型创新、礼赠仪式 | cultural-icon |
| 包装本身有机关、互动或功能巧思 | concept-mechanism |
| SKU 多、色彩编码强、需要货架识别 | brand-system |
| 酒、香水、美妆等依赖瓶型与工艺质感 | sensory-craft |
| 食品饮料依赖食欲、风味和快速识别 | appetite-direct |
| 可持续材料、减材、循环或透明供应链 | material-responsible |
| 新东方、茶、香、生活方式与留白 | oriental-lifestyle |

只选一个主原型。辅助原型最多一个，并且只补充 2–3 张镜头。例如：新中式茶礼盒可用 `oriental-lifestyle` 为主、`cultural-icon` 为辅；不要再叠加奢华酒类和快消货架语言。

## 七种叙事原型

### 1. cultural-icon：文化符号与产品雕塑

公开案例观察：Tiger Pan 的项目常先交代品牌/文化命题，再把瓶型、结构或核心符号作为主角，随后用产品英雄图、结构局部、雕刻/压纹/烫金细节与系列陈列完成证明。

推荐顺序：

`文化命题 → 符号/造型来源 → 英雄产品 → 结构轮廓 → 工艺细节 → 仪式场景 → 系列收束`

镜头特征：大轮廓、低干扰背景、产品像“物件”一样被观看；概念图最多 1–2 张，之后必须回到真实包装。适合酒、礼盒、滋补品、节庆限定。

避免：堆砌传统纹样、宫殿、祥云、丝绸来代替设计证据；文化解释不能比产品本身更长。

### 2. concept-mechanism：挑战、创意机制与互动验证

公开案例观察：Backbone Branding 常以 Challenge / Solution / End Product 展开，展示概念如何变成命名、造型、开启动作、量具、桌面或其他功能，并用人物/场景证明包装真的可互动。

推荐顺序：

`真实问题 → 一句话创意 → 视觉母版 → 结构机制 → 操作动作 → 使用后的表情/结果 → 系列变体`

镜头特征：开盒、拿取、测量、组合、摆放等动作必须可见；结构图与场景图的价值高于纯微距。适合创意礼盒、儿童、零食、茶点、体验型包装。

避免：只讲一个聪明故事却不展示结构如何工作；禁止虚构内托或机关。

### 3. brand-system：品牌系统、货架与一致中的变化

公开案例观察：Anagrama、Depot WPF 与 Pentagram 的大量案例把包装作为品牌系统的一部分：先明确客户/目标/解决方案，再展示 Logo、字体、颜色、信息层级、SKU 编码、不同规格、货架或跨媒介应用。

推荐顺序：

`市场/品牌问题 → 核心识别规则 → 单品标准视图 → SKU 色彩/编码 → 多规格家族 → 货架/运输/数字触点 → 系统收束`

镜头特征：正投影和整齐阵列多于戏剧性斜角；强调“共性骨架 + 变量规则”。适合快消、食品、美妆系列、DTC 品牌和品牌升级。

避免：把不同颜色当作系统的全部；必须展示排版、信息层级或结构共性。SKU 必须来自真实源文件。

### 4. sensory-craft：感官氛围与工艺证据

公开案例观察：Stranger & Stranger 等酒类包装团队强调瓶型轮廓、标签、纸张、玻璃、封口、礼盒和细节工艺；展示从完整瓶身逐步推进到标签微距，再进入饮用或收藏情境。

推荐顺序：

`氛围封面 → 瓶/盒英雄图 → 轮廓与标签 → 材料微距 → 工艺微距 → 礼盒/开合 → 饮用或收藏场景 → 结尾静物`

镜头特征：允许更深背景或更强明暗，但 Logo、标签和玻璃边缘必须清晰；用掠射光证明烫金、击凸、压纹和玻璃细节。适合酒、香水、高端护肤和收藏礼盒。

避免：把“高级”误解成黑金、烟雾、水滴和镜面石台；每个氛围元素必须服务产品材质。

### 5. appetite-direct：风味、食欲与快速传播

公开案例观察：mousegraphics 强调包装作为直接沟通工具，并在食品项目中结合清晰的产品识别、食物影像、口味差异和简明概念。展示要让观众迅速理解“是什么、什么味、为何不同”。

推荐顺序：

`一眼识别品类 → 单品正面 → 真实产品/原料 → 口味编码 → 组合陈列 → 使用/食用瞬间 → 货架或社交封面`

镜头特征：产品或原料可以出现，但不得遮挡包装；色彩更直接、镜头更短促、近景更有食欲。适合零食、饮料、乳品、调味品。

避免：用不真实的飞溅、悬浮原料和过度饱和代替食欲；场景必须符合真实尺度和食用方式。

### 6. material-responsible：材料、减材与责任证明

公开案例观察：OlssønBarbieri 与部分 Pentagram 案例会把材料选择、环境标准、结构减量、运输和使用周期纳入品牌叙事，而不把“环保”只写成一句口号。

推荐顺序：

`责任命题 → 材料全貌 → 结构拆解 → 减材/复用细节 → 使用与回收路径 → 系列/运输效率 → 克制收束`

镜头特征：自然材质、接缝、纸浆内托、补充装、透明度或单一材料结构成为主角；可加入爆炸式分解，但只能展示真实存在的组件。

避免：用绿叶、土壤、森林背景冒充可持续证据；没有数据时不声称减碳比例。

### 7. oriental-lifestyle：当代东方与呼吸感

公开案例观察：Fungo 等中国年轻化品牌案例常从生活态度、时间、愉悦、留白和自然色彩建立基调，再以包装、器物、手部动作与安静场景表达现代东方，而非复古符号堆叠。

推荐顺序：

`生活命题 → 色彩/留白 → 单品英雄图 → 器物关系 → 细节与触感 → 慢动作使用场景 → 系列色谱 → 留白收束`

镜头特征：自然柔光、克制器物、轻俯视或平视、较大留白；强调人与物的距离、呼吸和节奏。适合茶、香、文创、护肤和生活方式礼盒。

避免：泛化的禅意、枯枝、石头、香烟雾和水墨背景；东方感必须来自包装、色彩、字体和真实使用方式。

## 章节模块

从下列模块中选择，不必全部使用：

- **Hook**：一张封面建立记忆点。
- **Premise**：一句命题或一个真实问题。
- **Origin**：符号、材料、结构或文化来源。
- **Hero**：最完整、最准确的包装母版。
- **System**：Logo、信息层级、SKU、色彩或规格规则。
- **Structure**：开合、内托、组件、运输或人体工学。
- **Craft**：基材和工艺的近距离证据。
- **Use**：真实操作、食用、饮用、陈列或赠礼。
- **Scale**：货架、组合、家族或品牌触点。
- **Closure**：用轮廓、Logo 或系列色谱收束。

标准 10 张通常选择 7–8 个模块；同一模块可占两张，但连续两张必须一张提供整体、一张提供证据。

## 信息密度与节奏

- 开头 20%：少文字、强识别，让观众知道项目是什么。
- 中段 60%：结构、系统、工艺与使用证据交替，避免连续多张“漂亮静物”。
- 结尾 20%：系列、场景或强轮廓回扣开头。
- 一屏只讲一个主结论；概念说明不应覆盖包装主体。
- 每 2–3 张切换一次尺度：远景 → 中景 → 近景，再回到组合。
- 叙事越感性，越需要一张理性的正面/结构图校准；叙事越系统，越需要一张有温度的使用图建立情绪。

## 研究基准

公开页面仅作为方法观察来源，执行时不得下载、复制或重制其具体作品：

- Tiger Pan：文化命题、产品造型、雕塑式英雄图与工艺细节。
- Backbone Branding：Challenge / Solution / End Product、功能互动与人本故事。
- Anagrama：Client / Objective / Solution、目录式系列与标签/色彩系统。
- Depot WPF：消费洞察、品牌宣言、符号与 SKU 统一。
- Pentagram：策略问题、品牌识别规则、货架差异、跨触点和 DTC 开箱体验。
- Stranger & Stranger：酒类瓶型、标签、礼盒、材质和感官氛围。
- mousegraphics：包装沟通、食品影像、品类与风味快速识别。
- OlssønBarbieri：食品饮料故事、材料创新与责任表达。
- Fungo Design：当代东方、自然色彩、留白与生活方式语境。
