# 图生图提示词模板

每张提示词都从同一全局块开始。方括号内容必须被真实信息替换，不得凭空填写。

## 全局一致性块

```text
这是同一包装项目系列中的第 [NN] 张图。将图片 1 [视觉母版路径/角色] 作为受保护的最高视觉基准；图片 2... 为本镜头所需的真实面板、结构或 SKU 纹理参考。

包装为 [结构]，实际尺寸约 [mm]，严格保持母版中的长宽高比例、瓶肩/盒盖/袋底、封边、开合、标签位置和配件结构。

严格保留品牌名 [品牌]、Logo 形态、中文文字、主视觉、图形、颜色和版式；把源图作为纹理依据，不重新生成、不改写、不翻译任何文字。只允许显示参考素材中真实存在的包装面和信息。

【包装信息分级】A级必须准确可见：[主品牌/主标题]、[产品名或品类/口味]、[规格/数量]；B级按本镜头展示：[副标题/核心卖点/章节文案]；C级允许避开：[法规/配料/条码]。禁止为了减少乱码删除A级信息。

【字形类型】[排版文字]按字符语义核对；[书法字标/手写 Logo/篆刻]按母版视觉轮廓作为不可编辑图形纹理保留，不用 OCR 猜测，不转换成标准字体，不主动“纠正”笔画。用户已确认的字标区域直接冻结。

【图案特征锁】核心图案必须像素级沿用原始母版/平面稿，不重新绘制。核对特征点：[外轮廓]、[朝向]、[关键节点1]、[关键节点2]、[内部点阵/纹理]、[与标题的相对位置]。构图参考图不得作为图案纹理来源。

材质为 [材质]。工艺为 [工艺及区域]。工艺只附着在指定区域，强度克制，随曲面、折角、透视和同一光线方向变化。保持与母版相同的色值、白色基准、金属色和表面反射。
```

## 比例锁块

```text
【物理比例锁】包装实际尺寸 [W×H×D 或 Φ×H mm]，轮廓高宽比 [数值]；盖/身高度比 [数值]；标签高度/瓶身高度比 [数值]。严格以视觉母版的外轮廓作为形状蒙版式参考，不重新解释瓶肩、盒盖、袋底或圆角。
【画面占比锁】本镜头主包装占画面高度 [百分比范围]，底部基线位于画面高度 [百分比]。允许不同章节在 25%–95% 间改变视觉尺度，但不能改变包装自身比例。多产品时，明确写出等距等高或预设透视关系；同一阵列中的同规格包装像素高度偏差不超过 2%。
【系列画布锁】本子系列统一输出 [pixel_width × pixel_height px]，[横版/竖版]，[画幅比例]。本张实际像素宽高必须与画布母版完全一致，不得只保持近似画幅；不得通过拉伸、裁切、加边或补画布修正尺寸。
【镜头锁】使用 [焦段感]、[相机高度]、[距离关系]；禁止通过缩短/拉长包装适配构图。
```

视觉尺度不使用固定模板。按叙事选择极近 90%+、大 65–80%、中 40–60% 或小主体 25–35%；标准正面一般为 65–72%。macro 用盖沿、标签边或明确图形坐标作为裁切锚点。

## 艺术指导块

```text
【产品属性】[品类、使用环境、核心功能、形态、材质、工艺、主视觉关键词]。
【本张视觉母题】[从产品属性提炼出的场景/光线/构图动机]，不是通用奢华装饰。
【色谱位置】本张使用系列三段色谱中的 [基础识别色 / 功能场景色 / 情绪高潮色]：[背景色与承托色]；包装自身色值不得被环境色污染。
【背景降权】背景使用 [连续同色系/低饱和局部色雾/柔和光影]；背景内部最大反差和边界锐度低于产品轮廓反差。禁止半幅强色块、硬切双色墙或比产品更醒目的高饱和背景。
【构图理由】[为什么采用中心稳定/流线对角/阵列/负空间/环形等构图，它对应产品哪个特征]。
```

## 当前镜头块

```text
【概念发动机】[包装独特事实 + 产品行为/承诺 + 可摄影化动作]。
【证明动作】本张使用 [雕塑化 / 系统化 / 现象化 / 解剖化 / 情境化]，不得只靠换背景制造差异。
【本张目的】[英雄图/组合/结构/基材微距/工艺微距/场景/SKU/结尾]
【叙事章节】本张属于 [概念建立/产品识别/结构证明/工艺证明/使用体验/系统扩展/收束]，只承担这一项主要任务。
【构图】[产品数量、位置、高低、朝向、裁切和负空间]
【构图指纹】主体数量 [1/2/3+]；占画面 [极近/大/中/小]；观看方式 [正视/俯视/仰视/顶视/侧切/极近裁切]；空间骨架 [中轴/对角/环形/网格/放射/边缘/大留白]；动势 [静止/下沉/环游/聚拢/爆发/交错]；信息焦点 [轮廓/图形/结构/材质/工艺/使用/系统]。与前一张至少改变四项。
【负空间用途】若产品低于画面高度 35%，本张负空间用于 [章节级叙事文案 / 概念现象]。叙事文案精确为“[4–12 个汉字]”，辅助英文精确为“[英文]”；指定位置、对齐、字号层级和安全区，不添加其他文字。若不使用文案，必须让概念现象清晰承担视觉重心，禁止无目的空白。
【多产品密度】多产品时，产品群整体包络占画面宽度至少 78%、高度至少 65%；相邻间距小于单个产品宽度的 0.35。指定主产品与辅助产品关系，或使用严格满幅网格。禁止空心大环、平均散点和无信息的中央空洞。
【可见面】只显示 [正面/右侧/顶面/已知背面]；不得暴露没有纹理依据的面。
【文字风险地图】本镜头允许清晰出现 [主 Logo/主标题/SKU/无文字]；必须完全排除 [说明小字/法规区/条码/侧边残字]。任何不能完整准确生成的文字不得出现在画面边缘或虚焦区域。
【第二章最低信息契约】若本张属于产品识别/看清包装，必须完整保留A级信息；“无文字”选项无效。画外章节标题不能替代包装本身文字；A级信息生成不准确时改用正视或近平视重做。
【包装身份锚点】本镜头必须清晰保留 [核心插图/准确大号标题/标签边界与材质关系/独特结构坐标]，该锚点占据主要视觉区域；通用瓶盖/泵头占画面面积不超过 25%，空白无信息表面不成为视觉中心。
【原图局部保真】若核心插图被放大，只允许对原始母版做局部摄影化取景；改变画外背景、尺度、光线和景深，不重画插图，不补全、不简化、不改变线条、点阵、比例或位置。
【可见结构裁切锁】本镜头只放大母版中可见的 [角/边/接缝]；母版可见结构层数为 [N]、接缝数量为 [N]。禁止补出额外盒层、盖沿、接缝、灰板截面、护角或未知包边。
【动作或道具】[无/开盖/抽拉/真实品类道具]。道具最多 [N] 类，不遮挡 Logo、主标题或关键结构。
```

## 摄影块

```text
[4:5/1:1/16:9] 画幅，设计作品集级商业产品摄影。镜头感觉 [标准 50–85mm/微距]，相机高度 [平视/略俯视]，无广角畸变。[来自艺术指导卡的背景/场景]，保持表面纯净和可控；光线必须有明确动机，同时用中性补光保护包装色值。与整组保持同一色谱家族、材质语言和光质，但允许基础识别、功能场景、情绪高潮三段发生有逻辑的变化。
```

## 系列负面约束

在上游 `packaging-cmf-finishes` 的完整通用负面提示词后追加：

```text
禁止改变包装几何、尺寸比例、瓶肩、盒型、袋型、封边、开合和配件；禁止改变 Logo、品牌名、中文、主视觉、颜色、版式、材质和工艺位置；禁止虚构背面、侧面、法规文字、条码、内托、内容物或 SKU；禁止随机摄影风格和无逻辑换色，但允许概念驱动的色调、尺度与构图切换；禁止无关奢华道具、过度装饰、夸张悬浮、广角畸变、重复包装、缺失包装、融合包装；禁止沿用前一张的主体位置、完整居中站立方式和负空间结构；禁止拼贴板、九宫格、分镜板、水印和多余文字。

QA优先级：几何结构高于图案，高于文字，高于材质与背景。禁止为了文字完整或构图美观而增减结构层、改变盒体厚度、拉伸盖面、缩小辅助产品或制造不一致透视。
```

## 工艺微距补充

```text
使用真实微距摄影而非抽象材质图。画面中必须仍能识别该包装的局部结构和图形位置。以低角度掠射柔光显示 [工艺] 的物理高光/阴影，工艺边界准确，不溢出、不发光、不像贴纸；景深浅但 Logo/工艺关键边缘清晰。
```

若微距任务不是证明 Logo 或文字，且本张不属于第二章产品识别页，追加：

```text
本张只证明结构/材质，不展示 Logo、主标题、说明小字、条码或法规区。通过转动包装和裁切选择真实无字区域；禁止在边缘留下半个字、乱码或虚焦文字。若无法同时保证文字准确与构图质量，优先完全排除文字。

无字不等于无包装信息。保留该包装独有的核心插图、标签边界、印刷色块或结构坐标作为身份锚点；让标签/包装信息区域占画面 60% 以上，通用瓶盖不超过 25%。禁止把大面积空白瓶盖、空白瓶身或抽象黑色曲面作为唯一主体。
```

## 结构/开合补充

```text
严格按照 [盒型/瓶盖/袋口] 的真实开合逻辑展示 [动作]。组件数量和连接关系与参考资料一致。不得生成不存在的铰链、磁吸、内托、插舌、泵头、拉链、吸嘴或内容物。
```

## 场景图补充

```text
场景只用于说明 [真实使用情境]。包装仍是画面唯一主角，道具在材质、尺度和文化语境上与产品相关。控制道具数量与景深，不做泛化的花瓣、丝绸、烟雾、石台堆砌，不让环境色污染包装色值。
```

## 叙事标题补充

```text
本张是作品集章节页，不是电商海报。标题只使用来自包装真实卖点的短句：“[精确中文]”；辅助英文：“[精确英文]”。中文为第一层级，英文只做导航。保持大留白和明确网格，不添加卖点列表、按钮、促销信息、价格、Logo 副本或未经确认的功效。产品不得被文字遮挡。
```
