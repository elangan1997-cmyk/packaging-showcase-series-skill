# 质量门禁

每张图必须全部通过 A、B、C；系列完成后再通过 D。失败时重做当前图，不用本地代码修补。

## A. 身份一致性

- [ ] 先验收几何：包装外轮廓、面比例、厚度、结构层数和接缝数量与母版一致；若此项失败，立即淘汰，不再用文字或构图优点抵消。
- [ ] 是同一包装结构，不是相似的新设计。
- [ ] 长宽高、直径、瓶肩、盒盖、袋底和封边比例与母版一致。
- [ ] Logo、品牌名、中文标题、主视觉、色条和版式位置一致。
- [ ] 核心插图已与原始母版逐特征点核对：外轮廓、朝向、关键节点、内部点阵/纹理及相对位置均一致，不是同题材的重新绘制版本。
- [ ] 未出现错误文字、随机字符、额外 Logo、水印或多余标签。
- [ ] 画面四边和虚焦区没有残缺、乱码或变形文字；非文字任务已主动避开 Logo、说明小字、法规区和条码。
- [ ] 新出现的包装面有真实源纹理依据。
- [ ] 第二章产品识别页完整保留A级信息：主品牌/主标题、产品名或品类、规格/数量；没有用画外标题替代包装信息，也没有因规避乱码而清空文字。
- [ ] 书法字标、手写 Logo、篆刻等已按母版视觉字形核对；没有依据 OCR、标准字体或字面猜测擅自修字，用户确认过的版本未被再次改动。
- [ ] 结构/盒角微距仅放大母版可见结构；没有额外盒层、重复盖沿、双重接缝、未知灰板截面、金属护角或虚构包边。

## B. 材质与工艺

- [ ] 基材、透明度、粗糙度和反射与母版一致。
- [ ] 工艺类型、区域和强度一致，随透视和曲面正确变化。
- [ ] 工艺没有跨折线、热封边、切口或其他禁区。
- [ ] 微距仍能识别包装局部，不是脱离产品的抽象纹理。
- [ ] 微距中的文字要么完整准确且是信息焦点，要么被完全排除；不存在“顺带露出但无法核对”的文字。
- [ ] 微距保留至少一个专属包装身份锚点；标签/包装信息区占主要面积，通用瓶盖/泵头不超过画面 25%，无信息空白不成为主体。

## C. 摄影与物理

- [ ] 文件实际像素宽高与本子系列画布契约完全一致；不是只有画幅比例相同。
- [ ] 背景和道具能解释产品属性，不是换成另一种通用棚拍模板。
- [ ] 背景内部最大反差与边界锐度低于产品轮廓反差；没有抢眼的半幅强色块、硬切双色墙或背景第二主角。
- [ ] 背景表面纯净，阴影通透；环境色没有污染包装的标准色。
- [ ] 色温、对比度和光质属于同一色谱家族；变化符合基础/功能/高潮三段逻辑。
- [ ] 透视自然，无广角畸变、漂浮、穿插或错误接触面。
- [ ] 产品数量、配件、开合、内容物和道具符合镜头表。
- [ ] 画面承担明确的新信息任务，不是凑数换角度。
- [ ] 画面占比符合当前镜头预设；跨章节可以大幅变化，包装自身轮廓比例始终不变。
- [ ] 包装高宽比、盖/身比、标签/瓶高比与比例锚点一致。
- [ ] 与前一张相比，构图指纹至少改变四项；去掉背景后仍不是同一构图。
- [ ] 产品低于画面高度 35% 时，负空间明确用于章节标题或概念现象；没有无目的大空白。
- [ ] 章节标题来自包装真实卖点，字数克制、层级明确、无虚构功效，且不遮挡产品。
- [ ] 多产品画面首先读成一个强视觉块；产品群宽度占比至少 78%、高度至少 65%，没有空心大环或平均散点。
- [ ] 4 件以上只用于满幅网格、货架或连续边缘裁切；中央空洞超过 20% 时有明确标题或概念任务。
- [ ] 多产品画面没有为了辅助文字完整而改变产品比例、厚度或透视；非主产品的自然遮挡可接受，但主产品A级信息完整且可见字符未被改写。

## D. 整组一致性

- [ ] 同一子系列所有文件的像素宽度和高度逐张完全一致；不同平台尺寸已拆为独立子系列。
- [ ] 没有用本地拉伸、缩放、裁切、加边或补画布掩盖尺寸不一致；任一偏差都已通过重新生成当前张解决。
- [ ] 组图像同一摄影团队在同一视觉系统内完成。
- [ ] 色调可以明显变化但不是随机换色；核心图形、运动母题或光学特征形成连续性。
- [ ] 有远景、中景、近景和场景的节奏变化。
- [ ] 没有连续两张单品完整居中站立；没有两张构图指纹完全相同。
- [ ] 至少有极近裁切、小主体大环境、严格系统阵列、现象/动作四类画面。
- [ ] 包装身份、颜色、材质、工艺从第一张到最后一张无漂移。
- [ ] 所有核心图案均追溯到原始母版/平面稿；系列中的生成图没有被当作下一张的图案或纹理母版。
- [ ] 6/10/14 张各自承担独立信息任务，顺序形成完整叙事。
- [ ] 文件名、版本号和 `shot-manifest.md` 一致。
- [ ] 用户明确确认的候选版本已复制到项目输出并写入清单，没有被内部排序遗漏。

## 文字容错

中文和小号法规文字是图像模型的已知薄弱点。主标题、品牌名和 Logo 只要明显变形就不通过；A级信息缺失与变形同样不通过，不能以删除文字作为修复。背面小号文字若必须清晰展示，应优先使用源面板作为纹理参考并重做。多次失败时如实告知用户，不能声称达到印刷级准确。
