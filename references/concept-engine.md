# 概念母题与构图变奏

作品集图组不是同一张产品照的换背景版本。先从包装最独特的设计事实提取一个“概念发动机”，再让每张图从不同角度证明它。

## 一句话概念发动机

使用公式：

`包装独特事实 + 产品行为/承诺 + 可被摄影化的视觉动作`

示例：

- 扭曲透明瓶身 + 层流现象 + 折射、挤压、断层与光学焦散。
- 鲸鱼形软袋 + 儿童一眼记忆 + 游动、成群、尾部、挤压与条码识别。
- 黑金鱼食罐 + 缓沉配方和鱼体线稿 + 下沉、环游、聚散、鳞片式微距与水面折射。

概念发动机必须来自现有包装、真实功能或品牌图形。不得虚构包装机关、内容物、结构或功能。

## 五种证明动作

每个项目至少选择四种，且相邻画面不得使用同一种：

1. **雕塑化**：把单品当作强轮廓物件，强调外形和主视觉。
2. **系统化**：等比例阵列、正侧序列、SKU 编码或旋转序列。
3. **现象化**：用光、影、折射、流动或环境关系表现产品行为。
4. **解剖化**：极近裁切、材质剖面、标签环绕或工艺局部。
5. **情境化**：在真实使用尺度中证明品类、握持、陈列或环境关系。

“换背景色”“换台面”“产品从左移到右”不算新的证明动作。

## 构图指纹

为每张图记录六项：

- 主体数量：1 / 2 / 3+。
- 主体占画面：极近 90%+ / 大 65–80% / 中 40–60% / 小于 35%。
- 观看方式：正视 / 俯视 / 仰视 / 顶视 / 侧切 / 极近裁切。
- 空间骨架：中轴 / 对角 / 环形 / 网格 / 放射 / 边缘构图 / 大留白。
- 动势：静止 / 下沉 / 环游 / 聚拢 / 爆发 / 交错。
- 信息焦点：轮廓 / 图形 / 结构 / 材质 / 工艺 / 使用 / 系统。

相邻两张至少改变其中四项；整套不得有两张六项完全相同。若两张缩略图在一秒内看起来像同一构图，只保留更强的一张。

## 视觉尺度与物理比例分离

产品可以在不同章节中变大或变小，这是叙事节奏；包装自身的高宽比、盖身比、标签比例和同规格 SKU 的相对尺寸必须不变。

- 单品跨镜头：允许画面占比从 25% 到 95% 变化，但轮廓比例不得变化。
- 同一阵列中的同规格 SKU：像素高度偏差不超过 2%，基线一致；透视差异必须预先声明。
- 群像中的主次：若故意用前后景形成大小差，必须记录透视原因；不得假装等距却大小不一。
- 微距：是对已锁定包装的裁切，不是重新生成另一种盖子、瓶肩或标签高度。

## 色彩连续性

允许章节间出现显著色调变化，只要至少保持三个连续性锚点：包装身份、核心图形、同一光学特征、同一道具材料、同一运动母题或同一排版规则。

一套作品集可以从白/灰理性校准切到深色戏剧场景，再切到品牌 SKU 色场。禁止为了“统一”把十张都放进同一灰色棚景。

## 两道门禁

### 01/02 强制分离

标准正面通常是完整产品、正视中轴、占画面 65–72%。因此封面不得再是完整产品的大主体三分之二或 45° 视角：

- 方案 A：极近裁切 90%+，产品不完整，聚焦核心图形或材质。
- 方案 B：小主体 25–35%，大环境或强负空间，聚焦概念现象。

若 01 和 02 都能描述为“完整单品站立”，无论角度、背景和色调是否不同，直接判定失败。

组合图不得默认三件高低错落站台。只有包装结构本身是层级/阶梯概念时才可使用；其余项目优先紧密集群、连续边缘裁切、严格满幅网格、旋转序列或纵深交错。环形和放射不是默认答案，必须额外通过视觉密度门禁。

### 多产品视觉密度门禁

多产品不是把单品平均撒在画布上。先判断缩略图中产品群能否读成一个整体轮廓：

- 默认使用 2–3 件紧密集群，整体包络占画面宽度至少 78%、高度至少 65%。
- 相邻产品的可见间距通常小于单个产品宽度的 0.35；可以前后遮挡或边缘裁切，但不能物理穿插。
- 主产品必须明确，或所有产品形成严格网格；禁止“每个都一样重要但彼此很远”。
- 环形/放射构图只有在产品群仍然满幅，或中央明确承载标题、Logo、功能现象时才成立。
- 中央空洞超过画面 20% 且没有信息任务，直接判定散漫。
- 4 件以上的画面优先满幅网格、货架或连续边缘裁切；否则减少数量。

### 缩略图门禁

把候选图缩到约 200 px 宽快速比较：若轮廓、主体位置和负空间结构高度相似，判定重复，重做其中一张。

### 去背景门禁

想象去掉背景颜色和材质后，若两张仍是“同尺寸产品居中站立”，判定只是换皮。必须改变观看方式、空间骨架或信息焦点。
